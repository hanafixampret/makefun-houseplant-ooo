The funniest out-of-office auto-reply a houseplant would send, in 120 characters or fewer.

## Entry

> Out of office: the cactus filed for workers' comp after someone hugged it. Direct all complaints to the thorns.

## Run

```sh
node main.ts
```

Writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validates the 1–120 character gate, one line, and a byte-identical round-trip.
